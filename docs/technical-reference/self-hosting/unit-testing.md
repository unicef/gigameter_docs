# Unit Testing

Run unit tests to validate your self-hosted backend before connecting schools. The test suite requires the app to be set up locally first — see [Backend Installation](installation.md).

***

### Run the test suite

```bash
npm run test
```

### Run with coverage report

```bash
npm run test:cov
```

The coverage report shows which code paths are exercised by the tests. Review it before deploying to production to identify any untested areas in your local modifications.
