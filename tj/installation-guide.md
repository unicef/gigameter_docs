# Дастури насбкунӣ

Пеш аз оғоз, мутмаин шавед, ки дастгоҳи Шумо ба [Талаботи система](system-requirements.md) ҷавобгӯ аст.

{% hint style="info" %}
**Чизҳои зарурӣ:** тақрибан 10 дақиқа · рақами мактаби Шумо (ID) · компютери Windows, ки ба интернети мактаб пайваст аст
{% endhint %}

### Қисми 1: Насб кардани барнома

#### Қадами 1 — Боргирии Giga Meter

{% columns %}
{% column %}
Ба [meter.giga.global](https://meter.giga.global/) ворид шавед ва дар кунҷи болои рост ба **Download** (боргирӣ) пахш кунед.

Равзанаи боргирӣ кушода мешавад. Ҷои нигоҳдории файлро интихоб кунед ва ба "Save" (нигоҳ доштан) пахш кунед.

#### Қадами 3 — Ба анҷом расонидани устоди насб (Setup Wizard)

{% columns %}
{% column %}
Марҳилаҳои устоди насбро паси ҳам иҷро кунед:

* Агар равзанаи **Контроль учётных записей** (назорати ҳисобҳои корбарон) пайдо шавад, ба **Да** (бале) пахш кунед. Нашрдиҳанда UNICEF аст.
* **"Anyone who uses this computer (all users)"** (ҳама, ки аз ин компютер истифода мебаранд (ҳамаи корбарон))-ро интихоб кунед ва ба **Next** (навбатӣ) пахш кунед. Ин барномаро барои ҳамаи ҳисобҳо дар дастгоҳ дастрас мегардонад.

{% hint style="warning" %}
Хеле муҳим аст, ки барномаро барои ҳамаи корбарон насб кунед, агар дастгоҳе, ки барнома дар он насб мешавад, дар давоми ҳафтаи таҳсилӣ аз ҷониби якчанд корбар истифода шавад.
{% endhint %}

1. Ҷузвдони пешфарзи насбро (`C:\Program Files\unicef-pdca\Giga Meter`) тағйир надиҳед ва ба **Install** (насб кардан) пахш кунед.
2. Ба **Finish** (анҷом) пахш кунед. Қуттии **"Run Giga Meter"** (Giga Meter-ро иҷро кунед)-ро фаъол монед, то барнома фавран кушода шавад.
{% endcolumn %}

### Қисми 2: Бақайдгирии мактаби Шумо

#### Қадами 5 — Хушомадгӯӣ ва интихоби забон

{% columns %}
{% column %}
Қадамҳои бақайдгириро, ки дар барнома нишон дода шудаанд, риоя кунед. Барои гузаштан аз экранҳои муаррифӣ ба **Next** (навбатӣ) пахш кунед.

Барнома ба Шумо хотиррасон мекунад, ки бояд:

* Танҳо дар компютерҳое насб кунед, ки танҳо ба интернети мактаб пайваст ҳастанд
* Барои ҳар мактаб то 3 дастгоҳро ба қайд гиред (барои оғоз як дастгоҳ кофист)

Барои тағйир додани забони намоиш, дар кунҷи болои рост ба **English** пахш кунед ва аз рӯйхат интихоб намоед.

#### Қадами 7 — Тасдиқи кишвари Шумо

{% columns %}
{% column %}
Кишвари Шумо бояд ба таври худкор муайян шавад. Барои идома додан ба **Confirm** (тасдиқ кардан) пахш кунед.

{% hint style="warning" %}
Агар кишвари муайяншуда нодуруст бошад, кишвари дурустро аз рӯйхати мунсадил интихоб кунед ва ба **OK**, сипас ба **Confirm** пахш кунед.
{% endhint %}

Агар хатогӣ пайдо шавад:

* **"It looks like the country you selected may not be accurate"** (ба назар мерасад, ки кишвари интихобшуда дуруст набошад) — ин метавонад сабаби истифодаи VPN ё нишон додани кишвари дигар аз ҷониби нишонии IP бошад. Шумо метавонед бо пахш кардани **Confirm** идома диҳед.
* **"Sorry, Giga Meter is not available in \[...]"** (мутаассифона, Giga Meter дар [...] дастрас нест) — интихоби кишвари Шуморо санҷед. Агар мушкилот боқӣ монад, бо намояндаи UNICEF ё маъмуре, ки насбро роҳбарӣ кардааст, тамос гиред.
{% endcolumn %}

#### Қадами 8 — Ворид ва тасдиқ кардани рақами мактаб (ID)

{% columns %}
{% column %}
Рақами мактаб (ID)-ро, ки як рамзи беназир аз ҷониби ҳукумат додашуда аст, ворид кунед ва ба **Search ID** (ҷустуҷӯи ID) пахш кунед. Мактаби Шуморо аз натиҷаҳо бо пахш кардани **Select** (интихоб) интихоб кунед.

{% hint style="info" %}
Агар аз рақами мактаби Шумо (ID) мутмаин набошед, бо маъмури мактаб ё шӯъбаи IT тафтиш кунед.
{% endhint %}

Номи мактаби нишондодашударо дубора тафтиш кунед. Агар дуруст бошад, барои тасдиқ ба **YES** (бале) пахш кунед.

{% hint style="warning" %}
Пас аз пахш кардани **YES**, барои тағйир додани рақами мактаб (ID) бояд барномаро нест карда, аз нав насб кунед.
{% endhint %}
{% endcolumn %}

#### Қадами 9 — Тайёр аст!

{% columns %}
{% column %}
Мактаби Шумо акнун ба қайд гирифта шудааст. Барнома ба таври худкор аввалин санҷиши пайвастшавиро иҷро мекунад, то боварӣ ҳосил шавад, ки ҳама чиз кор мекунад. Ин метавонад андаке вақт гирад.

Агар санҷиш ноком шавад, дертар, вақте ки пайвастшавии интернет беҳтар шавад, дубора кӯшиш кунед. Агар санҷишҳо якчанд бор ноком шаванд, аксбардории экран гиред ва онро бо маъмуре, ки насбро роҳбарӣ кардааст, мубодила кунед.

{% hint style="info" %}
Пайвастшавии мактаби Шумо ҳарруза чен карда мешавад ва маълумот ба таври худкор ба Giga фиристода мешавад. Барои гирифтани маълумоти дақиқ, компютерро то ҳадди имкон дар як рӯз фаъол ва ба интернети мактаб пайваст нигоҳ доред.
{% endhint %}
{% endcolumn %}
