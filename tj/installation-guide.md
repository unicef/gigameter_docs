# Роҳнамои насбкунӣ

Пеш аз оғоз, мутмаин шавед, ки дастгоҳи Шумо ба [Талаботи система](system-requirements.md) мувофиқат мекунад.

{% hint style="info" %}
**Он чи зарур аст:** тақрибан 10 дақиқа · рақами мактаби Шумо · компютери Windows, ки ба интернети мактаб пайваст аст
{% endhint %}

#### Қадами 3 — Ба анҷом расонидани устоди насбкунӣ

{% columns %}
{% column %}
Марҳилаҳои устоди насбкуниро паси ҳам иҷро кунед:

* Агар равзанаи **User Account Control** (назорати ҳисобҳои корбар) пайдо шавад, **Yes** (бале)-ро пахш кунед. Ноширро UNICEF муайян мекунад.
* **«Anyone who uses this computer (all users)»** (ҳар кас, ки аз ин компютер истифода мебарад (ҳамаи корбарон))-ро интихоб кунед ва **Next** (навбатӣ)-ро пахш кунед. Ин барномаро барои ҳамаи ҳисобҳои ин дастгоҳ дастрас мекунад.

{% hint style="warning" %}
Хеле муҳим аст, ки барномаро барои ҳамаи корбарон насб кунед, агар аз ин дастгоҳ дар давоми ҳафтаи таҳсил якчанд нафар истифода баранд.
{% endhint %}

1. Ҷузвдони пешфарзи мақсадро (`C:\Program Files\unicef-pdca\Giga Meter`) тағйир надиҳед ва **Install** (насб кардан)-ро пахш кунед.
2. **Finish** (анҷом)-ро пахш кунед. Байрақчаи **«Run Giga Meter»** (Giga Meter-ро иҷро кунед)-ро нишондор нигоҳ доред, то барнома дарҳол кушода шавад.
{% endcolumn %}

### Қисми 2: Бақайдгирии мактаби Шумо

#### Қадами 5 — Хушомадгӯӣ ва интихоби забон

{% columns %}
{% column %}
Марҳилаҳои бақайдгириро, ки дар барнома нишон дода мешаванд, иҷро кунед. Барои гузаштан аз саҳифаҳои шинос **Next** (навбатӣ)-ро пахш кунед.

Барнома ба Шумо хотиррасон мекунад, ки бояд:

* Барномаро танҳо дар компютерҳое насб кунед, ки танҳо ба интернети мактаб пайвастанд

Барои иваз кардани забони намоиш, дар гӯшаи болои рост **English**-ро пахш кунед ва аз рӯйхат интихоб кунед.

#### Қадами 7 — Тасдиқи кишвари Шумо

{% columns %}
{% column %}
Кишвари Шумо бояд ба таври худкор муайян шавад. Барои идома додан **Confirm** (тасдиқ)-ро пахш кунед.

{% hint style="warning" %}
Агар кишвари муайяншуда нодуруст бошад, кишвари дурустро аз рӯйхати афтанда интихоб кунед ва **OK**-ро, сипас **Confirm**-ро пахш кунед.
{% endhint %}

Агар хатогие пайдо шавад:

* **«It looks like the country you selected may not be accurate»** (эҳтимол дорад кишвари интихобшуда дуруст набошад) — ин метавонад аз сабаби истифодаи VPN ё нишон додани кишвари дигар аз ҷониби суроғаи IP бошад. Шумо метавонед бо пахш кардани **Confirm** идома диҳед.
* **«Sorry, Giga Meter is not available in \[...]»** (мутаассифона, Giga Meter дар \[...] дастрас нест) — интихоби кишварро санҷед. Агар мушкилӣ идома ёбад, бо нуқтаи ҳамоҳангсози UNICEF ё маъмуре, ки насбкуниро роҳнамоӣ кардааст, тамос гиред.
{% endcolumn %}

#### Қадами 8 — Ворид ва тасдиқ кардани рақами мактаб (ID)

{% columns %}
{% column %}
Рақами мактабро — коди беназире, ки аз ҷониби давлат дода шудааст — ворид кунед ва **Search ID** (ҷустуҷӯи ID)-ро пахш кунед. Мактаби худро аз натиҷаҳо бо пахш кардани **Select** (интихоб) интихоб кунед.

{% hint style="info" %}
Агар аз рақами мактаби Шумо мутмаин набошед, бо маъмури мактаб ё шуъбаи ахбори техникӣ муроҷиат кунед.
{% endhint %}

Номи мактаби нишондодашударо аз назар гузаронед. Агар дуруст бошад, барои тасдиқ **YES** (бале)-ро пахш кунед.

{% hint style="warning" %}
Пас аз пахш кардани **YES**, барои иваз кардани рақами мактаб бояд барномаро тоза кунед ва аз нав насб кунед.
{% endhint %}
{% endcolumn %}

#### Қадами 9 — Тайёр аст!

{% columns %}
{% column %}
Мактаби Шумо акнун ба қайд гирифта шудааст. Барнома ба таври худкор аввалин санҷиши пайвастшавиро иҷро мекунад, то мутмаин шавад, ки ҳама чиз кор мекунад. Ин метавонад каме вақт гирад.

Агар санҷиш ноком шавад, баъдтар, вақте ки пайвастшавии интернет беҳтар мешавад, аз нав кӯшиш кунед. Агар санҷишҳо такроран ноком шаванд, скриншот гиред ва онро бо маъмуре, ки насбкуниро роҳнамоӣ кардааст, мубодила кунед.

{% hint style="info" %}
Пайвастшавии мактаби Шумо ҳар рӯз чен карда мешавад ва маълумот ба таври худкор ба Giga фиристода мешавад. Барои гирифтани маълумоти дуруст, компютерро то ҳадди имкон бештар соатҳои рӯз фаъол ва ба интернети мактаб пайваст нигоҳ доред.
{% endhint %}
