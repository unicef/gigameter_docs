# Талаботи барномасозон

Барои худмизбонии (self-hosting) Giga Meter гурӯҳи техникӣ лозим аст, ки қодир бошад барномаи Node.js-ро дар муҳити истеҳсолӣ ҷойгир, нигоҳдорӣ ва тағйир диҳад. Дар ин саҳифа маҷмӯи малакаҳои зарурӣ тавсиф шудааст.

Агар гурӯҳи Шумо ин малакаҳоро дар дохили худ надошта бошад, дида бароед, ки оё худмизбонӣ роҳи дуруст аст — бэкенди стандартии мизбонишудаи Giga ин бори иловагиро комилан бартараф мекунад.

***

### Малакаҳои зарурӣ

**Full-stack TypeScript**
Бэкенд бо NestJS ва интерфейси пеши барномаи Windows бо Angular сохта шудааст. Барои тарҳбандӣ Tailwind CSS истифода мешавад.

* [Angular](https://angular.dev/) — чаҳорчӯбаи фронтенд (барномаи Windows)
* [NestJS](https://nestjs.com/) — чаҳорчӯбаи бэкенд
* Tailwind CSS — тарҳбандӣ

**Пойгоҳи додаҳо**
Барнома PostgreSQL-ро бо Prisma ҳамчун ORM истифода мебарад. Гурӯҳи Шумо бояд бо инҳо шинос бошад:

* Асосҳои PostgreSQL — схема, дархостҳо, миграцияҳо
* Prisma — эҷоди клиентҳо, иҷрои миграцияҳо, фаҳмидани схема

**DevOps**
Барои иҷрои он дар муҳити истеҳсолӣ инҳо лозиманд:

* Идоракунии сервери Linux (Ubuntu 22.04 тавсия дода мешавад)
* Ҷойгиркунӣ ва идоракунии равандҳо (масалан, PM2, systemd)
* Асосҳои шабака ва амният — танзими HTTPS, қоидаҳои firewall, идоракунии портҳо
