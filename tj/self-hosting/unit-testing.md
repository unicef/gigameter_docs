# Санҷиши воҳидӣ (Unit Testing)

Пеш аз пайваст кардани мактабҳо, санҷишҳои воҳидиро иҷро кунед, то бэкенди худмизбонии Шуморо тасдиқ кунад. Барои иҷрои маҷмӯи санҷишҳо аввал бояд барнома дар компютери маҳаллӣ насб шуда бошад — нигаред ба [Насбкунии Бэкенд](installation.md) (бо забони англисӣ).

***

### Иҷрои маҷмӯи санҷишҳо

```bash
npm run test
```

### Иҷро бо гузориши фарогирӣ (coverage report)

```bash
npm run test:cov
```

Гузориши фарогирӣ нишон медиҳад, ки кадом қисматҳои код тавассути санҷишҳо тафтиш шудаанд. Пеш аз ҷойгиркунӣ ба муҳити истеҳсолӣ онро баррасӣ кунед, то қисматҳои санҷиданашудаи тағйиротҳои маҳаллии Шуморо муайян кунед.
