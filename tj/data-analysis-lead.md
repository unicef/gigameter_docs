# Дастури роҳбари таҳлили додаҳо

Ин дастур барои мансабдори давлатӣ пешбинӣ шудааст, ки барои истифодаи додаҳои Giga Meter масъул аст — аз муайян кардани он чи бояд чен карда шавад то ҳамроҳ кардани таҳлил ба қарорҳои давомдор. Ин қадамҳоро баробар бо равандҳои насбкунӣ иҷро кунед.

***

### Қадами 1 - Муайян кардани мавриди истифода

Пеш аз пайваст кардани ҳар корбар ба дашборд, муайян кунед, ки ҳукумат додаҳои Giga Meter-ро барои чӣ истифода мебарад. Ин муайян мекунад, ки кадом KPI-ҳо бояд назорат карда шаванд ва додаҳо кадом қарорҳоро дастгирӣ мекунанд.

Мавриди истифода ин ҳадафи умумӣ нест ("фаҳмидани пайвастшавии интернети мактабҳо"). Ин як давраи мушаххаси қарорқабулкунӣ мебошад: кадом шароит боиси баррасӣ мегардад, кӣ онро баррасӣ мекунад ва кадом амал натиҷа мешавад.

{% hint style="warning" %}
Бе мавриди истифодаи муайян, корбарони дашборд одатан ба додаҳо назар мекунанд, вале намедонанд бо онҳо чӣ бояд кард. Муайян кардани мавриди истифода асоси равандҳои таҳлили додаҳо мебошад.
{% endhint %}

**Мавриди истифода ба се савол ҷавоб медиҳад:**

1. **Ин додаҳо кадом қарорро дастгирӣ мекунанд?** масалан, кадом мактабҳо бояд барои беҳтаркунии провайдер афзалият дошта бошанд; оё провайдер шартҳои шартномаро иҷро мекунад; оё ҳадафи миллии пайвастшавӣ мувофиқи нақша пеш меравад
2. **Кӣ ин қарорро қабул мекунад?** масалан, воҳиди IT-и Вазорати маърифат, шӯъбаи нақшагирӣ, вазир
3. **Ин қарор чанд бор қабул карда мешавад?** масалан, ҳармоҳа барои баррасии амалиётӣ, ҳарсола барои нақшагирии буджет

**Навиштани мавриди истифодаи Шумо**

Кӯшиш кунед, ки як параграф бошад. Он бояд ба саволҳои зерин ҷавоб диҳад: чӣ мониторинг карда мешавад, чӣ ҳамчун мушкилот ҳисобида мешавад ва кӣ дар бораи он амал мекунад. Мисолҳои зерин ду навъро нишон медиҳанд:

> _Татбиқи сиёсат:_ "Мо Giga Meter-ро барои назорат кардани он истифода мебарем, ки оё мактабҳо ба меъёри миллии 1 Mbps ба ҳар донишомӯзи қайдшуда ҷавобгӯ мебошанд. Мактабҳое, ки дар давоми ду ҳафтаи пайдарпай поёнтар аз ин ҳадданд, ба ҳамоҳангсози провайдер гузориш дода мешаванд. Мутобиқат ҳармоҳа аз ҷониби шӯъбаи IT-и Вазорати маърифат баррасӣ карда мешавад."

> _Омодагии барнома:_ "Мо Giga Meter-ро барои муайян кардани мактабҳое истифода мебарем, ки пайвастшавии кофӣ эътимоднок доранд, то дар дарсҳои зинда пахши STEM иштирок кунанд. Мактабҳое, ки суръати боргирии устувори худро дар 30 рӯзи гузашта тасдиқ кардаанд, барои қайдшавӣ иҷозат дода мешаванд. Рӯйхат ҳармоҳа аз ҳониби гурӯҳи таълими рақамии Вазорати маърифат навсозӣ карда мешавад."

**Пайваст кардани мавриди истифода бо KPI-ҳо**

Пас аз равшан шудани мавриди истифода, KPI-ҳоеро муайян кунед, ки онро амалӣ мекунанд. [Ба Қадами 5 нигаред.](data-analysis-lead.md#step-5---define-kpis)

| Навъи мавриди истифода       | KPI-ҳои маъмулӣ                                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------------------------------- |
| Татбиқи сиёсат                | % мактабҳое, ки ба меъёри миллии суръат ҷавобгӯ мебошанд; # мактабҳое, ки 30+ рӯзи пайдарпай поёнтар аз меъёр мебошанд |
| Мутобиқат бо шартномаи провайдер | % мактабҳое, ки ≥ 80% суръати дар шартнома нишондодашударо мегиранд; # рӯзҳои поёнтар аз ҳадди SLA барои ҳар мактаб |
| Омодагии таълими рақамӣ       | % мактабҳое, ки ба ҳадди пайвастшавии муфид ҷавобгӯ мебошанд; # мактабҳое, ки барои қайдшавӣ дар барнома иҷозат дода шудаанд |
| Мониторинги татбиқ            | % мактабҳои насбшуда, ки дар 7 рӯзи гузашта гузориш додаанд; # мактабҳое, ки 28+ рӯз бе додаҳо мондаанд   |
| Хатти асосӣ ва таҳлили тамоюл | Суръати миёнаи боргирӣ барои ҳар ноҳия дар ҳар семоҳа; тағйироти солона (YoY) дар таъхири миёна          |

**Натиҷа:** Ҳуҷҷати кӯтоҳе, ки муайян мекунад додаҳои Giga Meter кадом қарорҳоро дастгирӣ мекунанд. Онро пеш аз аввалин ҷаласаи пайваст кардани дашборд бо гурӯҳи Giga мубодила кунед.

### Қадами 2 - Муайян кардани корбарони додаҳо ва таъини нақшҳои дастрасӣ

Муайян кунед, ки кӣ дар вазорат, ва берун аз он, ба додаҳои Giga Meter ниёз дорад ва дар кадом сатҳ. На ҳама ба дастрасии якхела ниёз доранд. Нуқтаҳои марказии сатҳи мактаб мумкин аст лозим бошад, ки мактаби худро дар Giga Maps бинанд; ҳамоҳангсозони минтақавӣ мумкин аст ба намуди филтршудаи минтақаи худ ниёз дошта бошанд; таҳлилгарони вазорат мумкин аст ба дастрасии содироти миллӣ ниёз дошта бошанд.

**Намунаҳои маъмули дастрасӣ:**

| Нақш                              | Канали маъмулӣ  | Доираи дастрасӣ         |
| ---------------------------------- | ---------------- | ------------------------ |
| Директори нақшагирӣ / вазир         | Дашборд          | Намуди миллӣ             |
| Ҳамоҳангсози IT-и Вазорати маърифат | Дашборд + API     | Ҳамаи мактабҳо           |
| Ҳамоҳангсози минтақавӣ             | Дашборд          | Танҳо филтри минтақавӣ   |
| Нуқтаи марказии мактаб             | Giga Maps         | Танҳо мактаби худ        |
| Шарики техникӣ / таҳлилгари додаҳо | API               | Содироти пурра           |

**Натиҷа:** Рӯйхати тасдиқшудаи корбарон ва сатҳҳои дастрасии зарурии онҳоро бо гурӯҳи Giga мубодила кунед. Ҳисобҳои дашборд ва API бар асоси нақш мебошанд ва бояд таъмин карда шаванд; корбарон намeтавонанд худ сабти ном кунанд.

### Қадами 3 - Пайваст кардани корбарони додаҳо ба каналҳои дастрасии онҳо

Додаҳои Giga Meter тавассути ду канал дастрас мебошанд. Кадом канал ба корбар лозим аст, аз тарзи кори онҳо бо додаҳо вобаста аст.

| Канал                                                    | Барои мувофиқтарин                                                                                                       | Дастрасӣ                                    |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| [**Дашборди Superset**](https://superset.giga.global)     | Гурӯҳҳои сиёсат, кормандони вазорат, ҳамоҳангсозони кишвар, ки ба диаграммаҳо ва ҷадвалҳо бе навиштани код ниёз доранд        | Маълумоти воридшавӣ аз ҷониби Giga таъмин карда мешавад |
| [**API**](https://maps.giga.global/docs/api/1)            | Гурӯҳҳои техникӣ, таҳлилгарони додаҳо, шариконе, ки мехоҳанд додаҳои Giga-ро ба низомҳои худ ворид кунанд ё таҳлилҳои шахсӣ гузаронанд | Калиди API аз ҳониби Giga таъмин карда мешавад |
| [**Giga Maps**](https://maps.giga.global)                  | Мактабҳо, нуқтаҳои марказии минтақавӣ ва ҷомеа, ки нуқтаи пайвастшавии мактабро мебинанд                                     | Оммавӣ, маълумоти воридшавӣ лозим нест         |

Ҳар ду канал ба ҳамон додаҳои асосӣ дастрасӣ доранд. Фарқият дар пешниҳод ва мутобиқшавӣ мебошад.

[**Дашборди Superset**](https://superset.giga.global)

Дашборд ҳафт экрани пешакин сохташуда пешниҳод мекунад, ки хулосаҳои сатҳи мактаб, тамоюлҳои суръат ва таъхир, тақсимоти ноҳиявӣ, ҷадвалҳои додаҳо барои ҳар ченкунӣ, пайгирии версияи барнома ва саломатии насбкуниро дар бар мегирад.

_Гирифтани дастрасӣ:_ Корбарон ҳисоби худро дар [superset.giga.global](https://superset.giga.global) эҳод мекунанд, сипас почтаи электронии сабтшудаи худро бо гурӯҳи Giga мубодила мекунанд, ки нақши мувофиқи сатҳи кишвариро таъин мекунад. Бе таъини нақш, корбарон метавонанд ворид шаванд, вале ҳеч додаҳоро намебинанд.

_Корбарон чӣ метавонанд кунанд:_ филтр кардан аз рӯи мактаб, ноҳия, фосилаи вақт ва сатҳи таҳсилот; содир кардани ҳар ҷадвал ба CSV; дидани силсилаи вақтӣ, диаграммаҳои box plot ва диаграммаҳои тақсимот; мубодилаи истинодҳои мустақим ба намудҳои мушаххаси дашборд.

_Корбарон чӣ намeтавонанд кунанд:_ таҳрир кардани дашборд ё диаграммаҳо (танҳо хониш); дастрасӣ ба додаҳои кишварҳои дигар.

[**API**](https://maps.giga.global/docs/api/1)

API-и Giga Maps дастрасии барномавӣ ба додаҳои пайвастшавии мактабро пешниҳод мекунад, барои гурӯҳҳое, ки мехоҳанд додаҳоро ба воситаҳои худ гиранд, гузоришҳои худкорро созанд ё додаҳои Giga-ро ба низомҳои давлатӣ ворид кунанд.

_Гирифтани дастрасӣ:_ Барои дархости калиди API ва санадҳо бо гурӯҳи Giga тавассути Нуқтаи марказии кишварии UNICEF Шумо тамос гиред.

_API чӣ пешниҳод мекунад:_ ченкуниҳои сатҳи мактаб (суръати боргирӣ, суръати боркунӣ, таъхир, вақти корӣ); маълумоти иловагии мактаб (ҷойгиршавӣ, сатҳи таҳсилот, рақами давлатӣ); додаҳои силсилаи вақтӣ, ки бо мактаб, ноҳия ва фосилаи вақт пурсида мешаванд; додаҳо тибқи иҷозатномаи CC BY 4.0 бароварда шудаанд.

**Пайвасткуниро пеш аз аввалин баррасии додаҳо гузаронед.** Нагузоред, ки аввалин бор корбарон додаҳоро дар ҷаласае бинанд, ки аз онҳо тафсир карданро интизор мебаранд.

**Натиҷа:** Ҳар корбари муайяншуда ворид шудааст ва метавонад мустақилона додаҳои заруриро барои нақши худ гирад.

{% hint style="info" %}
**Марҳилаи пайвасткунӣ**\
Формати ҷаласаи пайвасткунӣ: \[масалан, намоиши зинда, видеои сабтшуда, дастури хаттӣ]\
Санаи анҷом:\
Корбарони пайвастшуда: \[N]\
Корбарони боқимонда: \[N - номҳо ва сабаби таъхир]
{% endhint %}

**Экранҳои дашборд.** Дашборд ҳафт экрани пешакин сохташуда дорад, ки хулосаҳои мактаб, тамоюлҳои суръат ва таъхир, тақсимоти ноҳиявӣ, ҷадвалҳо барои ҳар ченкунӣ, пайгирии версияи барнома ва саломатии насбкуниро дар бар мегирад. Барои маълумоти экран ба экран дар бораи маънои ҳар сутун ва диаграмма, ба [Истифодаи дашборд](../../country-deployment/using-the-dashboard.md) (бо забони англисӣ) нигаред.

### Қадами 4 - Кӯмак ба гурӯҳ барои фаҳмидани нишондиҳандаҳои асосӣ

Giga Meter якчанд нишондиҳандаи техникиро гузориш медиҳад. Пеш аз он ки корбарон аз додаҳо хулоса кунанд, як маълумотномаи оддиро паҳн кунед, ки маънои ҳар нишондиҳанда ва арзиши хуб ё мушкилдорро дар шароити кишвар шарҳ медиҳад.

Шароит муҳим аст. Суръати боргирии 5 Mbps барои мактаби 200 донишомӯз мумкин аст заиф бошад, вале барои мактаби ибтидоии деҳот бо 30 донишомӯз кофӣ бошад. Муайян кардани ҳадҳои хосси кишвар ё хосси навъи мактаб додаҳоро нисбат ба меъёрҳои ҷаҳонӣ амалитар мегардонад.

**Нишондиҳандаҳои асосӣ:**

| Нишондиҳанда              | Чиро чен мекунад                                                          | Ҳамчун роҳнамои тахминӣ                                                |
| -------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **Суръати боргирӣ** (Mbps) | Суръати гирифтани додаҳо аз интернет тавассути мактаб                        | 1 Mbps ба ҳар иштирокчӣ барои занги садоӣ; 5 Mbps+ барои видеои HD дар ҳар синф |
| **Суръати боркунӣ** (Mbps) | Суръати фиристодани додаҳо аз мактаб, тарафи хориҷшавандаи занги видеоӣ       | Одатан поёнтар аз боргирӣ; пайвастҳои номутаносиб муқаррарӣ мебошанд        |
| **Таъхир** (мс)            | Таъхир байни дархост ва аввалин ҷавоб                                        | Поёнтар аз 50 мс фаврӣ ҳис карда мешавад; болотар аз 200 мс боиси таъхири назаррас мегардад |
| **Вақти корӣ** (%)         | Ҳиссаи соатҳои мактаб (8:00-20:00), ки пайвастшавӣ фаъол тасдиқ шудааст       | 99% = дастнорас барои ҳадди аксар \~3.6 соати вақти мактабӣ/моҳ            |
| **Мактаби фаъол**          | Ченкунии охирин дар давоми 21 рӯз                                            | Дастгоҳ фаъолона гузориш медиҳад                                            |
| **Мактаби дар хатар**      | Ченкунии охирин 22-28 рӯз пеш                                                | Бе пайгирӣ мумкин аст аз кор монад                                          |
| **Аз кор мондан**          | Ҳеч ченкунӣ дар 29+ рӯз                                                      | Бе ташрифи маҳал баргаштан душвор аст                                      |
| **Меъёри аз кор мондан**   | Мактабҳои аз кор монда ÷ шумораи умумии мактабҳои насбшуда                    | Болотар аз 10% = кӯшишҳои пайгириро зиёд кунед                             |

Барои таърифҳои пурраи ҳар майдон дар дашборд, ба [Луғати нишондиҳандаҳо](../../get-started/metric-glossary.md) нигаред.

**Натиҷа:** Ҳуҷҷати маълумотномаи нишондиҳандаҳо ба ҳамаи корбарони додаҳо пеш аз аввалин ҷаласаи баррасӣ паҳн карда мешавад.

{% hint style="info" %}
**Маълумотномаи нишондиҳандаҳо - \[Кишвар]**\
Суръати боргирӣ: чиро чен мекунад / шароити кишвар / ҳадди ташвиш\
Суръати боркунӣ: чиро чен мекунад / шароити кишвар / ҳадди ташвиш\
Таъхир: чиро чен мекунад / шароити кишвар / ҳадди ташвиш\
Вақти корӣ: чиро чен мекунад / шароити кишвар / ҳадди ташвиш
{% endhint %}

### Қадами 5 - Муайян кардани KPI-ҳо

Мавриди истифодаро ба 3-5 KPI-и чен карда шаванда табдил диҳед, ки ҳар яке формула, ҳад, масъул ва басомади баррасӣ дошта бошад. Маҷмуи KPI-ро хурд нигоҳ доред, то амалӣ бошад; рӯйхати 15 нишондиҳанда мунтазам баррасӣ намешавад.

| **Формула**            | Дар кадом тарз рақам ҳисоб карда мешавад        |
| **Ҳад**                 | Чӣ ҳамчун "хуб" ва чӣ ҳамчун "мушкилот" ҳисобида мешавад |
| **Масъул**             | Кӣ ин KPI-ро назорат мекунад ва амал мекунад    |
| **Басомади баррасӣ**   | Чанд вақт баррасӣ карда мешавад                 |
| **Амали ба вуҷуд омада** | Чӣ рӯй медиҳад, вақте ки ҳад вайрон карда мешавад |

### Қадами 6 - Муайян кардани раванди баррасии KPI ва боиси қарор шудан

Муайян кунед, ки KPI-ҳо чанд вақт баррасӣ мешаванд, кӣ баррасиро мегузаронад ва чӣ боиси амал мегардад. Ин равандро пеш аз он ки додаҳо ба ҷараён дароянд муайян кунед, на баъд аз он. Хатогии маъмултарин интизор шудан то мавҷуд шудани додаҳо пеш аз қарор кардан аст, ки бо онҳо чӣ бояд кард.

Формати баррасӣ набояд мураккаб бошад. Занги мунтазами 30-дақиқаии ҳармоҳа бо намуди дашборди муштарак назар ба гузориши семоҳа, ки ду ҳафта вақт мегирад, устувортар мебошад. Кишварҳое, ки ин равандро пешакӣ муайян мекунанд, бештар эҳтимол дорад, ки додаҳои Giga Meter-ро мунтазам истифода баранд. Кишварҳое, ки онро ғайрирасмӣ мегузоранд, одатан додаҳоро танҳо ҳангоми бӯҳрон истифода мебаранд.

**Натиҷа:** Раванди баррасиро ҷазм кунед ва пеш аз дастрас шудани аввалин додаҳо ба ҳамаи корбарони додаҳо паҳн кунед.

{% hint style="info" %}
**Раванди баррасии KPI**\
Масъули ҷаласа:\
Басомади баррасӣ: \[ҳарҳафта / ҳармоҳа / ҳарсеймоҳа]\
Формат: \[масалан, занги мунтазам, дашборди муштарак, хулосаи хаттӣ]\
\
**Ҳадҳо ва боисҳои KPI**\
\[Номи KPI] - ҳад: \[арзиш] - амал: \[чӣ рӯй медиҳад]\
\[Номи KPI] - ҳад: \[арзиш] - амал: \[чӣ рӯй медиҳад]\
\[Номи KPI] - ҳад: \[арзиш] - амал: \[чӣ рӯй медиҳад]
{% endhint %}

### Қадами 7 - Тавонманд кардани иқтидор барои таҳлили давомдор

Бо мурури вақт, гурӯҳҳои давлатӣ бояд қодир бошанд, ки таҳлилҳои худро бе дастгирии Giga таҳия кунанд: хулосаҳои пайвастшавии сатҳи мактаб, муқоисаи самаранокии провайдерҳо, гузоришҳои фарогирии минтақавӣ ва таҳлили тамоюл дар давоми вақт.

Аз хурд шурӯъ кунед. Дар соли аввал, ҳадаф ин аст, ки гурӯҳ мустақилона ба саволҳои асосии дашборд ҷавоб диҳад: кадом мактабҳо хуб амал мекунанд, кадомҳо аз кор мондаанд ва оё вазъият аз баррасии охирин беҳтар шудааст. Иқтидори таҳлилии амиқтар, ба монанди таҳлили регрессия, нишондиҳандаҳои шахсӣ ва гузоришдиҳии бар асоси API, метавонад бо афзоиши шиноӣ пайгирӣ карда шавад.

Агар дар кадом марҳила дастгирии амиқтар лозим бошад, бо гурӯҳи додаҳои Giga тамос гиред.

**Натиҷа:** Пас аз 6-12 моҳ, корбарони давлатӣ метавонанд таҳлилҳоро мустақилона таҳия ва тафсир кунанд, бе ишораи Giga.

{% hint style="info" %}
**Марҳилаи иқтидор - \[Сана]**\
Гурӯҳ метавонад мустақилона ба дашборд дастрасӣ ёбад ва филтр кунад: Ҳа / Не\
Гурӯҳ ҳадди аққал як хулосаи пайвастшавӣ таҳия кардааст: Ҳа / Не\
Гурӯҳ додаҳои самаранокии провайдерро баррасӣ кардааст: Ҳа / Не\
Дастгирии таҳлилӣ, ки ҳанӯз аз Giga лозим аст: \[агар мувофиқ бошад тасвир кунед]
{% endhint %}
