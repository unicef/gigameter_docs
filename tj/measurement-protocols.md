# Протоколҳои ченкунӣ

Giga Meter барои арзёбии сифати интернет дар мактабҳо аз ду санҷиш истифода мебарад: санҷиши суръат ва санҷиши ping.

***

### Санҷиши суръат

Санҷиши суръат протоколи NDT7-ро истифода мебарад, ки аз ҷониби [Measurement Lab (M-Lab)](https://www.measurementlab.net/) таҳия, нигоҳдорӣ ва мизбонӣ карда мешавад. Он суръати боргирӣ ва боркуниро дар фосилаҳои муайяншуда бо сервери наздиктарини M-Lab чен мекунад.

{% hint style="info" %}
Нусхаҳои қаблии Giga Meter протоколи NDT5-ро истифода мебурданд. Аз нусхаи 2.0 сар карда, ҳамаи ченкуниҳо тавассути NDT7 анҷом дода мешаванд.
{% endhint %}

**Он чиро чен мекунад:**

* Суръати боргирӣ (Mbps)
* Суръати боркунӣ (Mbps)
* Таъхир (ms)

***

### Санҷиши Ping

_Дар нусхаи 2.0.2, ноябри 2025 ҳамроҳ карда шудааст._

Санҷиши ping ҳар 15 дақиқа дар давоми соатҳои таълим (8:00-20:00 бо вақти маҳаллӣ) бо сервери наздиктарини Cloudflare иҷро мешавад.

**Он чиро чен мекунад:**

* Оё дастгоҳ дар он лаҳза ба интернет пайваст аст
* **Uptime** — фоизи ҷавобҳои муваффақи ping аз шумораи умумии кӯшишҳо дар дастгоҳҳои фаъолшуда дар давоми соатҳои таълим

### Серверҳои ченкунӣ

#### Серверҳои санҷиши суръат (NDT7 / M-Lab)

Giga Meter сервери санҷиши собитро истифода намебарад. Барои ҳар як санҷиши суръат, он тавассути Locate API-и M-Lab наздиктарин сервери дастраси M-Lab-ро интихоб мекунад:

1. Барнома бо `locate.measurementlab.net` муроҷиат мекунад ва наздиктарин сервери NDT-ро талаб мекунад
2. Locate API номи хостти наздиктарин сервери дастрасро бар асоси масири шабака бармегардонад
3. Барнома ба он сервер тавассути WebSocket/TLS дар порти 443 пайваст мешавад ва санҷиши NDT7-ро иҷро мекунад

Азбаски сервер дар лаҳзаи иҷро интихоб мешавад, як мактаб мумкин аст дар санҷишҳои гуногун бо серверҳои гуногун санҷида шавад, махсусан агар M-Lab серверҳоро илова, хориҷ ё барои хидматрасонӣ хомӯш кунад. Майдони `ServerInfo` дар ҳар як сабти ченкунӣ муайян мекунад, ки кадом сервер истифода шудааст.

**Дараҷаҳои сервери M-Lab:**

| Дараҷа                     | Тавсиф                                                                 |
| ------------------------ | --------------------------------------------------------------------------- |
| Ҷойгиркунии абрӣ        | Дар абр мизбонӣ шуда, аз ҷониби M-Lab идора мешавад                                              |
| Ҷойгиркунии пурраи сомона    | Якчанд сервери ҳамҷойгиршуда дар як нуқтаи ҳузур, аз ҷониби M-Lab идора мешавад |
| Ҷойгиркунии минималии сомона | Як сервер дар як нуқтаи ҳузур, аз ҷониби M-Lab идора мешавад                      |

Барои иловакунӣ ба рӯйхати иҷозатдодашудаи шабака, ниҳонсоз `*.measurementlab.net` ҳамаи дараҷаҳоро дар бар мегирад. Рӯйхати собити IP имконнопазир аст ва нигоҳдорӣ намешавад, зеро маҷмуи серверҳои M-Lab мунтазам тағйир меёбад.

**Чаро интихоби сервер ба натиҷаҳо таъсир мерасонад:**

Сервери M-Lab нуқтаи интиҳоии дурдаст барои санҷиши суръат мебошад. Сервери наздиктар (бо гардишҳои камтар, таъхири пасттар) одатан ба TCP имкон медиҳад, ки нисбат ба сервери дурдаст ба гузариши баландтар ноил шавад. Giga Meter барои кам кардани ин омил наздиктарин серверро интихоб мекунад, аммо масири шабакаи фарохудуд маънои онро дорад, ки мактаби наздик ба сарҳад баъзан мумкин аст бо сервере дар кишвари ҳамсоя санҷида шавад. Майдони `ServerInfo.Country` дар ҷавоби API ҷойгиршавии сервери интихобшударо нишон медиҳад.

#### Сервери санҷиши Ping / Uptime (Cloudflare)

Санҷиши ping-и uptime ба `speed.cloudflare.com` равона шудааст. Бар хилофи M-Lab, ин ҳадафи собит мебошад: шабакаи anycast-и Cloudflare пайвастшавиро ба таври худкор ба наздиктарин маркази додаҳои Cloudflare равона мекунад. Нишондиҳандаи uptime инъикос мекунад, ки оё дастгоҳ метавонад ба интернети умум дастрасӣ пайдо кунад, на пайвастшавӣ ба сервери мушаххас.
