# Талаботи система

### Талаботи ҳадди ақал

Барои насб кардани Giga Meter, компютер бояд ба талаботи ҳадди ақали зерин ҷавобгӯ бошад:

| Талабот                      | Мушаххасот                                              |
| ---------------------------- | ------------------------------------------------------- |
| **Системаи оператсионӣ**     | Windows 10 ё версияҳои навтар                           |
| **Навъи компютер**           | Компютери рӯимизӣ ё ноутбук                             |
| **Пайвастшавӣ ба интернет**  | Пайвастшавии фаъоли интернет дар мактаб                 |
| **Ҳаҷми холии хотираи диск** | Ҳадди ақал 500 МБ                                       |
| **Тарзи истифода**           | Компютере ки зуд-зуд, беҳтараш ҳар рӯз истифода мешавад |
| **Шабака**                   | Танҳо ба шабакаи интернети мактаб пайваст бошад         |

***

**Дар ҳар мактаб чанд компютер лозим аст?**

Барои оғоз як компютер кофист. Як компютере, ки дар давоми соатҳои дарсӣ фаъол мемонад, метавонад маълумоти мактабро мунтазам ирсол кунад. Дар ҳар мактаб то 5 компютерро ба қайд гирифтан мумкин аст. Чӣ қадаре ки компютерҳо зиёд бошанд, ҳамон қадар ченкуниҳо зуд-зуд гузаронида мешаванд. Инчунин, агар яке аз компютерҳо хомӯш бошад, компютери дигар метавонад ҷойи онро пур кунад.
{% endcolumn %}

{% column %}
<img src="https://gigabrand.vercel.app/illustrations/general/fill/connection.svg" alt="" height="100">

**Пайвастшавии симӣ афзалтар аст**

Агар имкон бошад, барномаро ҳадди ақал дар як компютере насб кунед, ки тавассути сими Ethernet ба шабака пайваст аст. Пайвастшавии симӣ имкон медиҳад, ки санҷиши суръати интернет устувортар ва дақиқтар анҷом дода шавад..
{% endcolumn %}

**Компютерро фаъол нигоҳ доред**

Ҳангоми фаъол будани компютер барнома дар пасзамина кор мекунад. Талош кунед, ки компютер дар давоми соатҳои дарсӣ фаъол бошад. Вақте компютер хомӯш аст ё дар ҳолати хоб (Sleep mode) қарор дорад, санҷишҳо гузаронида намешаванд.
{% endcolumn %}

{% column %}
<img src="https://gigabrand.vercel.app/illustrations/general/fill/people.svg" alt="" height="100">

**Ҳисобҳои чанд корбар**

Агар дар компютер якчанд ҳисоби корбарӣ мавҷуд бошад, Giga Meter-ро дар ҳар кадоми онҳо ба қайд гиред, то ҳамаи ченкуниҳо ба мактаб вобаста карда шаванд.
{% endcolumn %}
{% endcolumns %}

{% hint style="success" %}
Агар минбаъд ҳисобҳои нави корбарон илова шаванд, Giga Meter-ро дар онҳо низ насб ва ба қайд гиред.
{% endhint %}

{% hint style="warning" %}
Giga Meter-ро пайваста навсозӣ кунед. Огоҳиномаҳо барои навсозии барнома дар шакли паёмҳои равзанаӣ (pop-up) пайдо мешаванд. Ҳангоми гирифтани огоҳинома, барномаро аз нав оғоз кунед ва дастурҳои дар экран нишондодашударо иҷро намоед.

Истифодаи версияи кӯҳна метавонад ба дақиқӣ ва пуррагии натиҷаҳои ченкунӣ таъсир расонад.
{% endhint %}
