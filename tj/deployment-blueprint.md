# Нақшаи татбиқ

Пеш аз оғози татбиқ ин пурсишномаро пур кунед. Пурсишнома барои мувофиқ кардани дастаи иҷрокунанда ва Giga дар масъалаҳои стратегия, доира ва меъёрҳои муваффақият пешбинӣ шудааст ва он дар тамоми давраи татбиқ ба ҳуҷҷати муштараки истинодии Шумо табдил меёбад.

***

### 1. Кишвар ва заминаи татбиқ

{% hint style="info" %}
**Вазорат/Идораи роҳбарикунанда:**\
\
**Вазорат/Идораи дастгирикунанда:**\
\
**Асосноккунии татбиқ** - Ҳадафи асосии насб кардани Giga Meter чист?\
• _масалан, эҳтиёт кардани маълумоти пойгузор, пайгирии пешравӣ дар назди сиёсат, назорати фаъолияти таъминкунандаи хидматрасон_\
\
**Абзорҳои мониторинги мавҷуда** - Ҳозир барои ченкунии пайвастшавии интернети мактабҳо абзорҳое истифода мешаванд?\
\
**Мутобиқат бо стратегияи миллӣ** - Ин чӣ гуна бо нақшаҳои калонтари таҳсилоти рақамӣ ё технологияҳои иттилоотӣ-коммуникатсионии (ТИК) миллӣ мувофиқат мекунад? Оё сиёсат ё стандартҳое мавҷуданд, ки ҳадди ақали пайвастшавии мактабҳоро муайян мекунанд?\
\
**Модели пайвастшавии мактаб** - Интернети мактаб чӣ гуна таъмин карда мешавад: марказонида аз ҳисоби вазорат ё аз ҳисоби мактабҳои алоҳида?
{% endhint %}

### 2. Нақшагирии насбкунӣ

{% hint style="info" %}
**Доираи татбиқ** - Шумора ва навъи мактабҳои ҳадаф:\
\
**Марҳилабандӣ** - Андоза ва меъёрҳои гурӯҳи озмоишӣ, сониб марҳилаҳои васеъшавӣ:\
\
**Роҳбари насбкунӣ** - Кӣ барои ҳамоҳангсозии насбкунӣ масъул аст?\
• _масалан, воҳиди ТИК-и Вазорати маълумот, ҳамоҳангсозони минтақавӣ_\
\
**Рақами мактаб (ID)** - Оё мактабҳо ва насбкунандагон ба рақамҳои расмии мактаб дастрасӣ доранд? Агар нею, ин масъала чӣ гуна ҳал карда мешавад?\
\
**Дастрасии дастгоҳ** - Оё дастгоҳҳои Windows дар мактабҳои ҳадаф мунтазам истифода мешаванд ва ба интернет пайваст ҳастанд?\
\
**Таълим ва дастгирӣ** - Насбкунандагон чӣ гуна таълим дода мешаванд? Кадом каналҳои дастгирӣ мавҷуд хоҳанд буд?\
• _масалан, вебинар дар Zoom, гурӯҳи WhatsApp, хатти телефонии кӯмак_\
\
**Иртибот бо мактабҳо** - Оё канали марказонидашуда ё рӯйхати тамос барои алоқа бо мактабҳо мавҷуд аст?\
\

### 3. Нигоҳдорӣ ва дастгирӣ

{% hint style="info" %}
**Ҷонибдор** - Кӣ дар дохили вазорат (ё ташкилоти шарик) барои маълумот ҳимоят хоҳад кард ва татбиқро фаъол нигоҳ хоҳад дошт?\
\
**Шахсони масъул дар мактаб** - Шахсони масъул дар сатҳи мактаб чӣ гуна таъин ва нигоҳ дошта мешаванд?\
\
**Ҳамоҳангсозии минтақавӣ** - Оё сохтори ҳамоҳангсозони минтақавӣ мавҷуд аст? Агар бале, роҳбарон киҳоянд?\
\
**Дастгирӣ пас аз насбкунӣ** - Кӣ ҳалли масъалаҳоро пас аз татбиқ идора мекунад? Роҳи мурроҷиат ба Giga чӣ гуна аст?\
\
**Нақшаи устуворӣ** - Мониторинг пас аз татбиқи ибтидоӣ чӣ гуна идома дода мешавад?\
• _масалан, ҳамҷомеаи амалӣ, ҷаласаҳои мунтазами баррасӣ, дастури такрори насбкунӣ_
{% endhint %}

***

### 4. Истифода ва моликияти маълумот

{% hint style="info" %}
**Истифодабарандагони асосии маълумот** - Кӣ маълумотро истифода мебарад ва барои чӣ ҳадаф?\
• _масалан, воҳиди нақшагирии Вазорати маълумот барои баррасии шартномаи таъминкунандаи интернет, дафтарҳои минтақавӣ барои муайян кардани афзалиятҳои дастгирии мактаб_\
\
**Каналҳои дастрасӣ** - Истифодабарандагон чӣ гуна ба маълумот дастрасӣ пайдо мекунанд?\
• _масалан, лавҳаи Giga Maps, API, ҳисоботҳои содиршуда_\
\
**Мисоли истифода** - Маълумоти Giga Meter кадом қарор ё амали мушаххасро асоснок мекунад?\
• _Нигаред ба_ [_Дастури роҳбари таҳлили маълумот - Қадами 1_](data-analysis-lead.md)\
\
**Ниёз ба дастгирии таҳлилӣ** - Оё вазорат барои тафсири маълумот, сохтани нишондиҳандаҳо ё ворид кардани натиҷаҳо ба сиёсат ба дастгирӣ ниёз дорад?
{% endhint %}

### 6. Пешниёзҳои инфрасохтор ва пайвастшавӣ

{% hint style="info" %}
**Дастрасии сервери M-Lab** — Оё дар дохили кишвар сервери M-Lab NDT7 мавҷуд аст? Харитаи серверҳои [M-Lab](https://www.measurementlab.net/status/)-ро бисанҷед. Агар сервери маҳаллӣ мавҷуд набошад, санҷишҳои суръат ва таъхир роҳи байналмилалиро, на шабакаи дохилиро, ченкунӣ мекунанд. Оё ин масъала бо ҳукумат баррасӣ шудааст?\
\
**Маҳалли нигоҳдории маълумот** — Оё қонуни миллӣ ё сиёсати ҳукумат талаб мекунад, ки маълумоти пайвастшавии мактаб дар серверҳои дохилӣ нигоҳ дошта шавад ё дар дохили кишвар коркард шавад?\
\
**Худмизбонӣ** — Агар талаботи маҳалли нигоҳдории маълумот амал кунад, оё ҳукумат худмизбонии қисми паси Giga Meter-ро баррасӣ мекунад? Худмизбонӣ дастаи техникии махсус (TypeScript, PostgreSQL, Linux DevOps) ва ду серверро талаб мекунад. Барои талаботи пурра ба [Худмизбонии Giga Meter](../technical-reference/self-hosting.md) (бо забони англисӣ) нигаред.\
\
**Дастрасии шабака** — Оё дастрасии манзилҳои зарурии шабака дар девори оташини (firewall) мактаб ва вазорат тасдиқ шудааст? Ба [Манзилҳои шабака ва танзими девори оташин](../technical-reference/network-destinations.md) (бо забони англисӣ) нигаред.
{% endhint %}
