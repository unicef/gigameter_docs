# Маълумотнома оид ба API

API-и Giga Meter дастрасии барномавиро ба сабтҳои бақайдгирии мактабҳо, фарогирии кишвар ва ченкуниҳои алоҳидаи пайвастшавӣ фароҳам меорад.

**URL-и асосӣ:** `https://uni-ooi-giga-meter-backend.azurewebsites.net`

**Муҳаррики интерактивӣ:** [maps.giga.global/docs/explore-api](https://maps.giga.global/docs/explore-api)

**Дархости дастрасӣ:** Бо гурӯҳи Giga тавассути Нуқтаи Тамоси Миллии UNICEF (UNICEF Country Focal Point) тамос гиред. Ҳамаи нуқтаҳои интиҳоӣ (endpoints) калиди API-ро талаб мекунанд.

***

### Санҷиши ҳаққонияти истифодабаранда (Authentication)

Ҳама дархостҳо бояд токени Bearer-ро дар сарлавҳаи `Authorization` дошта бошанд:

```
Authorization: Bearer <your-api-key>
```

Дархостҳо бидуни токени эътиборнок хатои `401 Unauthorized`-ро бармегардонанд.

***

### Нуқтаҳои интиҳоӣ (Endpoints)

#### Мактабҳо

`GET /api/v1/dailycheckapp_schools`

Рӯйхати мактабҳои дар пойгоҳи додаҳои Giga Meter бақайдгирифташударо бармегардонад.

**Параметрҳо:**

| Ном                  | Навъ   | Тавсиф                                                                                        |
| -------------------- | ------ | ---------------------------------------------------------------------------------------------- |
| `page`                | рақам | Саҳифаҳое, ки пеш аз ҷамъоварии натиҷаҳо гузаронда мешаванд. Агар `page=2` ва `size=10` бошад, 20 сабт гузаронда мешавад. Пешфарз: `0` |
| `size`                | рақам | Шумораи мактабҳое, ки бояд баргардонда шаванд. Пешфарз: `10`                                        |
| `giga_id_school`      | сатр  | Филтр аз рӯи ID-и мактаби Giga (формати UUID, масалан `2abb47dd-3fca-44b1-b6c8-0ec0c863c236`)                |
| `country_iso3_code`   | сатр  | Филтр аз рӯи рамзи ISO3-и кишвар (масалан `IND`, `MDA`, `BRA`)                                             |

**Намунаи дархост:**

```
GET /api/v1/dailycheckapp_schools?size=1&country_iso3_code=ALB
Authorization: Bearer <your-api-key>
```

**Намунаи ҷавоб:**

```json
{
  "success": true,
  "data": [
    {
      "id": "11583751",
      "giga_id_school": "7c32006a-c3d1-3798-9082-be9b8222d872",
      "os": "windows",
      "app_version": "2.0.2",
      "country_code": "AL",
      "is_blocked": false,
      "created_at": "2026-06-17T07:45:14.976Z",
      "is_active": null,
      "wifi_connections": []
    }
  ],
  "timestamp": "2026-06-19T15:58:21.751Z",
  "message": "success"
}
```

**Майдонҳои асосии ҷавоб:**

| Майдон           | Чи дар бар мегирад                                                                   |
| ---------------- | ---------------------------------------------------------------------------------- |
| `giga_id_school` | UUID-и дохилии мактаб дар Giga — барои дархости ченкуниҳои мактаби мушаххас истифода баред |
| `os`             | Системаи оперативӣ, ки дар ин дастгоҳ Giga Meter-ро иҷро мекунад                             |
| `app_version`    | Нусхаи насбшудаи Giga Meter                                                          |
| `country_code`   | Рамзи ISO2-и кишвари мактаби бақайдгирифташуда                                            |
| `is_blocked`     | Оё дастгоҳ аз ҷониби бекенд манъ шудааст                                             |
| `created_at`     | Вақти бақайдгирии аввалия                                                             |

***

#### Кишварҳо

`GET /api/v1/dailycheckapp_countries`

Рӯйхати кишварҳоеро бармегардонад, ки ҳадди ақал як мактаби бақайдгирифтаи Giga Meter доранд.

**Параметрҳо:**

| Ном     | Навъ   | Тавсиф                                        |
| ------- | ------ | ---------------------------------------------- |
| `page`  | рақам | Саҳифаҳое, ки гузаронда мешаванд. Пешфарз: `0`                  |
| `size`  | рақам | Шумораи кишварҳое, ки бояд баргардонда шаванд. Пешфарз: `10` |

**Намунаи дархост:**

```
GET /api/v1/dailycheckapp_countries?size=10
Authorization: Bearer <your-api-key>
```

**Намунаи ҷавоб:**

```json
{
  "success": true,
  "data": [
    {
      "id": "44",
      "code": "AL",
      "code_iso3": "ALB",
      "name": "Albania",
      "country_id": "178",
      "created_at": "2026-02-16T12:36:39.529Z"
    }
  ],
  "timestamp": "2026-06-19T15:58:21.966Z",
  "message": "success"
}
```

**Майдонҳои асосии ҷавоб:**

| Майдон       | Чи дар бар мегирад                                                                        |
| ----------- | ----------------------------------------------------------------------------------------- |
| `code`      | Рамзи ISO2-и кишвар                                                                       |
| `code_iso3` | Рамзи ISO3-и кишвар — онро ҳамчун `country_iso3_code` дар дархостҳои Мактабҳо ва Ченкуниҳо истифода баред |
| `name`      | Номи кишвар                                                                            |

***

#### Ченкуниҳо

`GET /api/v1/measurements`

Натиҷаҳои алоҳидаи санҷиши Giga Meter-ро бармегардонад. Ҳар сабт як санҷиши суръат аст, ки дар як мактаб, дар як лаҳза гузаронда шудааст.

**Параметрҳо:**

| Ном                  | Навъ   | Тавсиф                                                                                 |
| -------------------- | ------ | ------------------------------------------------------------------------------------- |
| `page`                | рақам | Саҳифаҳое, ки гузаронда мешаванд. Пешфарз: `0`                                                                 |
| `size`                | рақам | Сабтҳо дар як саҳифа. Ҳадди ақал: `1`, ҳадди аксар: `100`. Пешфарз: `10`                                       |
| `orderBy`             | сатр  | Сутуне, ки аз рӯи он мураттаб карда мешавад. `created_at`-ро барои тартиби афзоянда (ASC) ва `-created_at`-ро барои тартиби камшаванда (DESC) гузоред. Пешфарз: `-timestamp` |
| `giga_id_school`      | сатр  | Филтр аз рӯи UUID-и мактаби Giga                                                                  |
| `country_iso3_code`   | сатр  | Филтр аз рӯи рамзи ISO3-и кишвар                                                                 |
| `filterBy`            | сатр  | Сутун барои филтр кардан (масалан, `timestamp`, `created_at`)                                        |
| `filterCondition`     | сатр  | Оператори муқоиса: `lt`, `lte`, `gt`, `gte`, `eq`                                         |
| `filterValue`         | сатр  | Қиммате, ки бо он муқоиса карда мешавад (масалан, `2024-01-14` ё `2024-01-14T15:13:30.824Z`)                  |

**Намунаи дархост — 5 ченкунии охирин барои мактаби мушаххас:**

```
GET /api/v1/measurements?size=5&giga_id_school=7c32006a-c3d1-3798-9082-be9b8222d872&orderBy=-timestamp
Authorization: Bearer <your-api-key>
```

**Намунаи дархост — ҳамаи ченкуниҳо баъд аз санаи муайян:**

```
GET /api/v1/measurements?filterBy=timestamp&filterCondition=gt&filterValue=2024-06-01T00:00:00.000Z&country_iso3_code=MDA
Authorization: Bearer <your-api-key>
```

**Намунаи ҷавоб:**

```json
{
  "success": true,
  "data": [
    {
      "id": "7179786",
      "Timestamp": "2026-06-17T14:30:44.369Z",
      "DeviceType": "windows",
      "Notes": "daily",
      "ClientInfo": {
        "ASN": "AS60471",
        "ISP": "AS60471 Mobitel sh.p.k.",
        "City": "Kashar",
        "Region": "Tirana",
        "Country": "AL",
        "Latitude": 41.3497,
        "Longitude": 19.7103,
        "Timezone": "Europe/Tirane"
      },
      "ServerInfo": {
        "City": "Podgorica",
        "FQDN": "ndt-iupui-mlab1-tgd01.mlab-oti.measurement-lab.org",
        "Country": "ME",
        "Metro": "tgd"
      },
      "Download": 93346.08,
      "Upload": 31959.84,
      "Latency": 5
    }
  ],
  "timestamp": "2026-06-19T15:58:22.000Z",
  "message": "success"
}
```

**Майдонҳои асосии ҷавоб:**

| Майдон                | Воҳид | Чи дар бар мегирад                                                          |
| -------------------- | ---- | ---------------------------------------------------------------------------- |
| `Timestamp`          | —    | Вақти гирифтани ченкунӣ (ISO 8601)                                                 |
| `DeviceType`         | —    | Системаи оперативии дастгоҳи ченкунанда                                          |
| `Notes`              | —    | Навъи оғози ченкунӣ (`daily` = ба нақша гирифташуда; `manual` = аз ҷониби корбар оғозшуда) |
| `ClientInfo.ASN`     | —    | Рақами Системаи Мустақил (Autonomous System Number)-и провайдери интернети мактаб                |
| `ClientInfo.ISP`     | —    | Номи хониши осони провайдери интернет                                                   |
| `ClientInfo.Country` | —    | Рамзи ISO2-и кишваре, ки IP-и мизоҷ дар он ҷойгир аст                                       |
| `ServerInfo.City`    | —    | Ҷойгиршавии сервери M-Lab NDT, ки барои ин санҷиш истифода шудааст                                    |
| `Download`           | Kbps | Суръати боргирии чоряккардашуда дар ин санҷиш                                                 |
| `Upload`             | Kbps | Суръати боркунии чоряккардашуда дар ин санҷиш                                                 |
| `Latency`            | ms   | Таъхири рафту баргашт (round-trip), ки дар ин санҷиш чен шудааст                                            |

{% hint style="info" %}
Қиммати `Download` ва `Upload` бо **Kbps** оварда шудаанд. Барои табдил ба Mbps ба 1000 тақсим кунед (масалан, 93346 Kbps = 93.3 Mbps).
{% endhint %}

***

### Саҳифабандӣ (Pagination)

Ҳамаи нуқтаҳои интиҳоӣ аз саҳифабандии офсетбунёд тавассути `page` ва `size` истифода мебаранд.

| Барои гирифтани   | Истифода баред   |
| ---------------- | ---------------- |
| 10 сабти аввал | `page=0&size=10` |
| 10 сабти навбатӣ  | `page=1&size=10` |
| Сабтҳои 21–30    | `page=2&size=10` |

Массиви `data` дар ҳар ҷавоб дақиқан `size` сабтро дар бар мегирад (ё камтар, агар ба охири маҷмӯаи додаҳо расида бошед). Майдони шумораи умумӣ вуҷуд надорад — то он даме такрор кунед, ки `data` массиви холиро барнагардонад.

***

### Филтр кардани сана

Барои дархост аз рӯи фосилаи вақт дар нуқтаи интиҳоии Ченкуниҳо `filterBy`, `filterCondition` ва `filterValue`-ро якҷоя истифода баред:

```
GET /api/v1/measurements
  ?filterBy=timestamp
  &filterCondition=gt
  &filterValue=2024-01-01T00:00:00.000Z
  &country_iso3_code=MDA
  &size=100
  &orderBy=timestamp
```

Қиммати қабулшудаи `filterCondition`: `lt` (камтар аз), `lte` (камтар ё баробар ба), `gt` (бештар аз), `gte` (бештар ё баробар ба), `eq` (баробар ба).

Қиммати сана метавонад ба шакли `YYYY-MM-DD` ё тамғаи вақти пурраи ISO 8601 (`YYYY-MM-DDTHH:MM:SS.sssZ`) дода шавад.

***

### Қолаби ҷавоб (Response envelope)

Ҳар ҷавоб як қолаби ягонаро пайравӣ мекунад:

```json
{
  "success": true,
  "data": [ ... ],
  "timestamp": "2026-06-19T15:58:21.751Z",
  "message": "success"
}
```

Дар сурати хато, `success` ба `false` табдил меёбад ва `message` тавсифи мушкилотро дар бар мегирад.
