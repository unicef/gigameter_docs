# Самтҳои шабакавӣ ва танзими девори оташин

Ин саҳифа барои маъмурони IT пешбинӣ шудааст, ки бояд девори оташин, серверҳои прокси ё системаҳои филтркунии мазмунро танзим кунанд, то трафики Giga Meter иҷозат дода шавад.

{% hint style="info" %}
Ҳамаи пайвастшавиҳои Giga Meter аз **номҳои домейнӣ, ки тавассути DNS ҳал мешаванд**, тавассути **HTTPS (порти 443)** истифода мебаранд. Барнома ба нишониҳои IP-и статикии сахтгузошта пайваст намешавад. Рӯйхати сафеди домейнҳо дар асоси DNS кофӣ аст; рӯйхати IP-и статикӣ лозим нест ва нигоҳ дошта намешавад.
{% endhint %}

### Рӯйхати сафеди ҳадди ақали девори оташин

Ин қоидаҳои трафики хориҷшавандаро илова кунед. Тамоми трафик танҳо тавассути порти 443 HTTPS мегузарад; пайвастшавиҳои воридотӣ талаб карда намешаванд.

| Қоида | Домейн                                         | Эзоҳот                                                       |
| ----- | ----------------------------------------------- | -------------------------------------------------------------- |
| 1     | `uni-ooi-giga-meter-backend.azurewebsites.net` | API-и асосӣ, зарур                                              |
| 2     | `locate.measurementlab.net`                    | Ёфтани сервери M-Lab, зарур                                     |
| 3     | `*.measurementlab.net`                         | Серверҳои санҷиши суръати M-Lab (маҷмуи динамикӣ), зарур        |
| 4     | `api.ipinfo.io`                                | Геолокациякунии IP, зарур                                       |
| 5     | `ipv4.geojs.io`                                | Муайянкунии IP-и эҳтиётӣ, зарур                                 |
| 6     | `speed.cloudflare.com`                         | Ченкунии ping, зарур                                            |
| 7     | `excubo.unicef.io`                             | Мониторинги хатогиҳо, ихтиёрӣ, барои ченкунии асосӣ зарур нест  |
| 8     | `github.com` / `*.github.com`                  | Навсозии барнома, ихтиёрӣ, метавонад дастӣ идора карда шавад    |

### Тавсифи трафик

#### Санҷиши суръат (протоколи NDT7)

| Хусусият        | Тафсилот                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| Протокол         | NDT7 тавассути WebSocket/TLS (wss://)                                                             |
| Порт             | 443                                                                                                |
| Самт             | Дуҳтарафа: боргирӣ — сервер→мизоҷ; боркунӣ — мизоҷ→сервер                                          |
| Мазмуни маълумот | Маълумоти бинарии тасодуфӣ (интиқоли якчанд барои ченкунии суръат)                                 |
| Давомнокӣ        | тахминан 10-15 сония барои ҳар санҷиш                                                              |
| Басомад          | То 4 санҷиш дар як рӯз: 1 ҳангоми оғози дастгоҳ + 3 дар фосилаҳои тасодуфӣ (8-12, 12-16, 16-20 бо соати маҳаллӣ) |
| Мақсад           | Сервери наздиктарини M-Lab, ки ба таври динамикӣ интихоб мешавад                                   |

{% hint style="warning" %}
Трафики санҷиши суръат таркишҳои кӯтоҳ ва баландсуръатро ба вуҷуд меорад, ки дар системаҳои мониторинги трафик метавонанд ба фаъолияти шубҳанок монанд бошанд. Ин ҳолати муқаррарӣ аст: санҷиш бояд пайвастшавиро то ҳадди пуррагӣ бор кунад, то зарфияти онро чен кунад. Ҳар таркиш тахминан 10-15 сония давом мекунад ва то 4 маротиба дар як рӯз рух медиҳад.
{% endhint %}

### Интихоби сервери M-Lab

Инфрасохтори санҷиши суръати M-Lab шабакаи серверҳое мебошад, ки дар саросари ҷаҳон тақсим шудаанд. Giga Meter ба сервери собит пайваст намешавад; он ҳар дафъа ҳангоми санҷиш наздиктарин серверро интихоб мекунад:

1. **Ёфтан:** Барнома тавассути HTTPS ба `locate.measurementlab.net` муроҷиат мекунад, то наздиктарин серверро дархост кунад
2. **Интихоб:** Хидмати Locate номи домейни (hostname) наздиктарин сервери NDT-ро бармегардонад (на нишонии IP)
3. **Санҷиш:** Барнома ба сервери интихобшуда тавассути WebSocket/TLS (wss://) дар порти 443 пайваст мешавад

Азбаски маҷмуи серверҳои M-Lab динамикӣ аст ва серверҳо мунтазам илова, хориҷ ва нигоҳубин карда мешаванд, тартиб додани рӯйхати IP-и статикӣ ғайриимкон аст. Аломати умумии DNS `*.measurementlab.net` ҳам Хидмати Locate ва ҳам ҳамаи серверҳои NDT-ро дар саросари ҷаҳон дар бар мегирад ва равиши дурусти сафедкунӣ мебошад.

### Хулосаи меъмории барнома

| Қабат              | Технология                          |
| -------------------- | -------------------------------------- |
| Frontend            | Angular 19 + Ionic 6                   |
| Муҳити иҷрои десктоп | Electron 29                            |
| Backend             | NestJS (Node.js / TypeScript)          |
| Пойгоҳи маълумот    | PostgreSQL                             |
| Санҷиши суръат       | NDT7 (M-Lab), Apache 2.0                |
| Мизбонии абрӣ        | Microsoft Azure                        |
| Мониторинги хатогиҳо | Sentry (аз ҷониби UNICEF ICTD худ мизбонӣ карда мешавад) |

**Ҷараёни маълумот:**

1. Мактаб барномаро насб мекунад → бо рақами мактаб (ID) ба қайд мегирад → сервери бекенд бақайдгириро нигоҳ медорад
2. Барнома санҷишҳои суръати ба нақшагирифташудаи (NDT7) ва ченкунии ping (Cloudflare)-ро иҷро мекунад
3. Натиҷаҳо тавассути HTTPS REST API ба Giga Backend бор карда мешаванд
4. Маълумоти ҷамъбастшуда дар [Giga Maps](https://maps.giga.global/) (оммавӣ) намоиш дода мешавад
5. Тобовари ҳангоми офлайн: агар шабака дастнорас бошад, ченкуниҳо дар маҳал нигоҳ дошта мешаванд ва ҳангоми барқарор шудани пайвастшавӣ ҳамоҳанг карда мешаванд (то 7 рӯз нигоҳдории офлайн)
