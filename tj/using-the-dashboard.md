# Истифодаи дашборд

Маълумоти Giga Meter тавассути дашборди [Apache Superset](https://superset.giga.global) нашр мешавад. Варақаҳо хулосаи мактабҳо, тамоюлҳои суръат ва таъхир, тақсимот аз рӯи ноҳия, ҷадвалҳои ҳар як ченкунӣ, пайгирии версияи барнома ва ҳолати насбро нишон медиҳанд. Ин саҳифа маълумотномаи экран ба экран аст.

Барои маълумот дар бораи гирифтани ҳисоб ва интихоби роҳи дастрасии мувофиқ барои ҳар корбар, ба [Дастури роҳбари таҳлили маълумот](../docs/deployment/data-analysis-lead.md) (бо забони англисӣ) нигаред.

{% hint style="info" %}
**Гирифтани дастрасӣ:** дар [superset.giga.global](https://superset.giga.global) ҳисоб кушоед, сипас суроғаи почтаи электронии сабтшудаи худро ба гурӯҳи Giga фиристед — онҳо ба Шумо нақши сатҳи кишвар таъин мекунанд. Бидуни нақш, Шумо метавонед ворид шавед, вале ягон маълумотро намебинед.
{% endhint %}

***

### Қисматҳои дашбордҳои Superset

Ба ҳамаи варақаҳо тавассути навори варақаҳо дар болои дашборд дастрас шудан мумкин аст.

| Экран                               | Ба чӣ ҷавоб медиҳад                                                                                   |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| **Хулоса**                          | Чанд мактаб дар харита ҳастанд, чанд адад тавассути Giga Meter гузориш медиҳанд ва рақамҳои асосии суръат ва таъхир |
| **Пайвастшавӣ · Суръат ва таъхир**  | Тамоюлҳои рӯзонаи суръат ва таъхир, ва тақсимоти суръат дар байни мактабҳо                              |
| **Пайвастшавӣ · Ноҳия**             | Суръати миёна аз рӯи ноҳия, инчунин ҷадвали ҳар мактаб бо графикҳои хурд (sparkline)                     |
| **Ҷадвалҳои маълумот · Сабтшуда**   | Як сатр барои ҳар мактаби сабтшуда, майдонҳои асосии амалиётӣ барои пайгирӣ                              |
| **Ҷадвалҳои маълумот · Ченкуниҳо**  | Як сатр барои ҳар санҷиш, аз ҷумла ташхиси Wi-Fi, ки дар вақти ченкунӣ сабт шудааст                      |
| **Пайгирии барнома**                | Кадом версияи Giga Meter дар саросари кишвар кор мекунад; шумораи гузоришҳои рӯзона                     |
| **Пайгирии насб**                   | Кӣ фаъол аст, кӣ хомӯш шудааст, ва сатҳи қатъшавӣ (drop-off) аз рӯи ноҳия                                |

<details>

<summary>Экрани 1 - Хулоса</summary>

Намуди аввалин. Ду рақами асосӣ: мактабҳои дар харита ва мактабҳое, ки тавассути Giga Meter гузориш медиҳанд, пас аз он рақамҳои асосии суръат ва таъхир.

<figure><img src="../.gitbook/assets/Superset 1.png" alt=""><figcaption></figcaption></figure>

| Чӣ мебинед                          | Истилоҳ           | Маънояш                                                                     |
| ------------------------------------ | ------------------ | ----------------------------------------------------------------------------- |
| Мактабҳо дар Giga Maps (масалан 1.19k) | Giga Maps        | Мактабҳое, ки ҷойгиршавии онҳо муайян ва дар Giga Maps нашр шудааст            |
| Мактабҳо бо Giga Meter (масалан 81)  | Giga Meter        | Аз мактабҳои дар харита буда, чанд адад барномаро кор фармуда, ченкуниҳоро мефиристанд |
| Фаъол (масалан 75)                   | Мактаби фаъол      | Мактабҳое, ки дар 21 рӯзи охир хониш фиристодаанд                             |
| Қатъшуда (масалан 5)                 | Қатъшавӣ (Drop-off)| Мактабҳое, ки 29 рӯз ва зиёда хомӯшанд, бидуни сафари ҷойӣ баргаштани онҳо гумонбар аст |
| Дар хатар (масалан 1)                | Мактаби дар хатар  | Мактабҳое, ки дар давраи хомӯшии 22-28 рӯз қарор доранд                        |
| Боргирии миёна (масалан 85.59 Mbps)  | Суръати боргирӣ    | Миёнаи тамоми мактабҳо ва тамоми ченкуниҳо дар доираи муайяншуда              |
| Таъхири миёна (масалан 59 ms)        | Таъхир             | Тахминан ҳадди болоии он чизе, ки дар видеоқунғирод фаврӣ ҳис карда мешавад   |
| Ҳамаи ченкуниҳо (масалан 32.4k)      | Ченкунӣ            | Санҷишҳои алоҳидаи Giga Meter дар тамоми мактабҳо дар давраи вақти интихобшуда |

</details>

<details>

<summary>Экрани 2 - Пайвастшавӣ · Суръат ва таъхир</summary>

Тамоюлҳои рӯзонаи суръат ва таъхир, инчунин тақсимоти намуди box-plot, ки нишон медиҳад таҷриба дар байни мактабҳо то чӣ андоза устувор аст.

<figure><img src="../.gitbook/assets/Superset 2.png" alt=""><figcaption></figcaption></figure>

| Чӣ мебинед  | Истилоҳ             | Маънояш                                                                     |
| ----------- | -------------------- | ------------------------------------------------------------------------------ |
| Хатти сиёҳ  | Суръати боргирӣ      | Боргирии миёнаи рӯзона, бо Mbps                                                |
| Хатти кабуд | Суръати боркунӣ      | Боркунии миёнаи рӯзона, одатан аз боргирӣ пасттар                             |
| Box plot    | Тақсимоти суръат      | Қуттии сояафкан = 50% миёнаи мактабҳо; нуқтаҳо = холатҳои ғайримуқаррарӣ      |
| Диаграммаи поёнӣ | Таъхир          | Таъхири миёнаи рӯзона бо миллисония                                            |
| Воҳиди меҳвари Y | Миллисония (ms) | Камтар аз 50 ms барои видеоқунғирод бароҳат аст; зиёда аз 200 ms таъхири назаррасро ба вуҷуд меорад |

</details>

<details>

<summary>Экрани 3 - Пайвастшавӣ · Ноҳия</summary>

Суръати миёна аз рӯи ноҳияи маъмурӣ, сипас ҷадвали ҳар мактаб бо графикҳои хурд (sparkline).

<figure><img src="../.gitbook/assets/Superset 2.1.png" alt=""><figcaption></figcaption></figure>

| Чӣ мебинед            | Истилоҳ                        | Маънояш                                                                         |
| ---------------------- | -------------------------------- | ---------------------------------------------------------------------------------- |
| Сутунҳои хокистарӣ     | Суръати боргирӣ                  | Боргирии миёна дар як ноҳия                                                        |
| Сутунҳои сабз          | Суръати боркунӣ                  | Дар паҳлӯи боргирӣ ҷойгир аст, пайвастшавиҳои асимметриро ба осонӣ намоён мекунад |
| Сутуни "Last value"    | Суръати боргирӣ                  | Хонишиахирин аз як санҷиши Giga Meter                                             |
| Сутуни "Weekly Avg"    | Миёнаи ҳаракаткунанда            | Миёнаи ҳамаи ченкуниҳо аз ҳафт рӯзи охир                                          |
| Сутуни "WoW %"         | Фоизи ҳафта ба ҳафта (Week-over-Week) | -91% маънои онро дорад, ки миёнаи ин ҳафта 91% пасттар аз ҳафтаи гузашта аст, ин ҳолат бояд баррасӣ шавад |

</details>

<details>

<summary>Экрани 4 - Ҷадвалҳои маълумот · Сабтшуда</summary>

Як сатр барои ҳар мактабе, ки тавассути Giga Meter сабт шудааст. Барои пайгирии амалиётӣ бисёр муфид аст.

<figure><img src="../.gitbook/assets/Superset 3.png" alt=""><figcaption></figcaption></figure>

| Номи сутун                     | Маънояш                                                                       |
| ------------------------------- | -------------------------------------------------------------------------------- |
| `school_id_govt`                | Рамзи расмии мактаб дар кишвар, ки аз рақами дохилии Giga фарқ мекунад            |
| `num_measurements`              | Шумораи умумии санҷишҳои Giga Meter, ки мактаб то ҳол гузаронидааст               |
| Рӯзҳо аз охирин ченкунӣ         | 0 = имрӯз хониш фиристодааст; ҳар рақами дигар аз сифр огоҳии барвақт аст         |
| `num_devices_registered`        | Чанд компютери мактаб ба Giga Meter пайваст шудааст                              |
| `most_recent_app_version`       | Навтарин версияи Giga Meter, ки дар ягон дастгоҳи мактаб кор мекунад              |

{% hint style="success" %}
Барои муайян кардани мактабҳое, ки аввал бояд пайгирӣ шаванд, сутуни "days since last measurement"-ро аз рӯи тартиби нузулӣ (аз калон ба хурд) мураттаб кунед.
{% endhint %}

</details>

<details>

<summary>Экрани 5 - Ҷадвалҳои маълумот · Ченкуниҳо</summary>

Як сатр барои ҳар санҷиши алоҳидаи Giga Meter, аз ҷумла ташхиси Wi-Fi, ки дар вақти ченкунӣ сабт шудааст.

<figure><img src="../.gitbook/assets/Superset 3.1.png" alt=""><figcaption></figcaption></figure>

| Номи сутун            | Маънояш                                                                    |
| ---------------------- | ------------------------------------------------------------------------------ |
| `load_speed`           | Суръати боргирӣ, ки дар ин санҷиши мушаххас сабт шудааст, бо Mbps               |
| `isp_asn_clean`        | Муайян мекунад, ки шабакаи кадом провайдер ин санҷишро хизматрасонӣ кардааст   |
| `avg_latency`          | Таъхире, ки дар ин санҷиши мушаххас сабт шудааст, бо ms                        |
| `isp_clean`            | Номи провайдери интернет (ISP), ки аз маълумоти сабтшудаи барнома тоза карда шудааст |
| `detected_wifi_ssid`   | Номи шабакаи Wi-Fi, ки дастгоҳ ҳангоми санҷиш ба он пайваст буд                |
| Сигнали Wi-Fi          | Қувваи сигнал бо dBm, ҳарчи ба сифр наздиктар, ҳамон қадар қавитар (-60 солим; -85 суст) |
| Суръати TX-и Wi-Fi     | Суръати интиқоли маълумот ба роутер бо Mbps, ҳангоми суст шудани пайванди бесим паст мешавад |

{% hint style="info" %}
Агар мактабе `load_speed`-и паст дошта бошад, вале таъхир солим ва сигнали Wi-Fi қавӣ бошад, эҳтимол дорад, ки мушкилот на дар шабакаи дохилии мактаб, балки дар тарафи провайдери интернет (ISP) бошад.
{% endhint %}

</details>

<details>

<summary>Экрани 6 - Пайгирии барнома</summary>

Кадом версияи Giga Meter дар саросари кишвар паҳн шудааст ва ҳар рӯз чанд мактаб маълумот мефиристад.

<figure><img src="../.gitbook/assets/Superset 4.png" alt=""><figcaption></figcaption></figure>

| Чӣ мебинед        | Маънояш                                                                       |
| ------------------ | ---------------------------------------------------------------------------------- |
| Диаграммаи ҳалқавӣ (donut) | Ҳар порча = версияи гуногуни Giga Meter. Як порчаи ягона = версияи якхела     |
| Диаграммаи сутунӣ  | Ҳар сутун = шумораи мактабҳое, ки дар он рӯз ҳадди ақал як ченкунӣ фиристодаанд    |
| Хатти хокистарӣ    | Ҳисоби ҳаракаткунандаи 7-рӯза, ки фуруд омадани рӯзҳои истироҳатро ҳамвор карда, тамоюли рушдро нишон медиҳад |

{% hint style="success" %}
Пас аз навсозии версия, ин экранро барои мактабҳое, ки ҳанӯз бо версияҳои кӯҳна кор мекунанд, назорат кунед. Диаграммаи ҳалқавии пароканда маънои онро дорад, ки баъзе дастгоҳҳо навсозиро гум кардаанд.
{% endhint %}

</details>

<details>

<summary>Экрани 7 - Пайгирии насб</summary>

Намуди санҷиши ҳолат. Нишон медиҳад, ки кӣ фаъол аст, кӣ хомӯш шудааст ва сатҳи қатъшавӣ аз рӯи ноҳия чӣ гуна аст.

<figure><img src="../.gitbook/assets/Superset 5.png" alt=""><figcaption></figcaption></figure>

| Чӣ мебинед                | Маънояш                                                                    |
| -------------------------- | -------------------------------------------------------------------------------- |
| Шумораи мактабҳои фаъол    | Мактабҳое, ки дар 21 рӯзи охир ченкунӣ фиристодаанд                              |
| Шумораи қатъшавӣ           | Мактабҳое, ки 29 рӯз ва зиёда хомӯшанд, бидуни мудохила баргаштани онҳо гумонбар аст |
| Сатҳи қатъшавӣ             | Шумораи қатъшавӣ ÷ шумораи умумии мактабҳои насбшуда. Афзоиши ин сатҳ маънои заруран лозим будани дастгириро дорад |

{% hint style="warning" %}
Сатҳи қатъшавии зиёда аз 10% аломати он аст, ки бояд пайгирӣ бо кормандони IT-и мактаб зиёд карда шавад ё сафарҳои азнавнасбкунӣ банақша гирифта шаванд.
{% endhint %}

</details>
