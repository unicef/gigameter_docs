# Махфият ва амният

Giga Meter аз ҷониби ташаббуси Giga-и ЮНИСЕФ таҳия ва нигоҳдорӣ мешавад. Дар ин саҳифа маълумот дода мешавад, ки барнома кадом маълумотро ҷамъоварӣ мекунад, чӣ гуна он ҳифз мешавад ва кадом чаҳорчӯбаҳои идоракунӣ татбиқ мешаванд.

**Мухтасар:** Giga Meter танҳо ченкуниҳои техникии пайвастшавиро ҷамъоварӣ мекунад. Он маълумоти шахсӣ, маълумоти хонандагон ё сабтҳои кормандони мактабро ҷамъоварӣ намекунад. Тамоми маълумоти ченкунӣ ҳамчун маълумоти кушод тибқи литсензияи стандартии байналмилалӣ нашр карда мешавад.

***

### Маълумоти ҷамъоваришаванда

Giga Meter сифати пайвастшавии интернети мактабро чен мекунад. Маълумоте, ки он ҷамъоварӣ мекунад, комилан техникӣ аст:

* Суръати боргирӣ ва боркунӣ, таъхир ва гум шудани баста (packet loss)
* Провайдери хидматрасони интернет (ISP) ва навъи шабака
* Навъи дастгоҳ ва версияи барномаи Giga Meter
* Вақти санҷиш ва ҷойгиршавии сервери санҷиш

Он ягон ном, сабтҳои хонандагон, маълумоти кормандон ё маълумоти ҷойгиршавиро, ба ғайр аз он чи барои муайян кардани ISP лозим аст, ҷамъоварӣ намекунад. Барои рӯйхати пурраи майдонҳо ба [Giga Meter кадом маълумотро интиқол медиҳад?](../../get-started/faq.md) нигаред.

***

### Литсензияи маълумот

Тамоми маълумоти ченкунии Giga Meter тибқи литсензияи [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/) нашр карда мешавад. Ин маънои онро дорад, ки:

* Ҳар кас метавонад ба маълумот дастрасӣ дошта бошад, онро мубодила кунад ва истифода барад
* Ҳар кас метавонад дар асоси он абзорҳо ё гузоришҳо созад
* Ягона талабот ин зикр кардани манбаъ (Giga/ЮНИСЕФ) аст

***

### Сиёсати махфият

Матни пурраи сиёсати махфияти Giga Meter дар [meter.giga.global/privacy-policy](https://meter.giga.global/privacy-policy) нашр шудааст. Он дар бар мегирад, ки барнома чӣ ҷамъоварӣ мекунад, маълумот чӣ гуна истифода мешавад ва кадом шартҳо барои мактабҳое, ки барномаро истифода мебаранд, татбиқ мегарданд.

***

### Дар куҷо маълумот нигоҳ дошта мешавад

Ҳамаи маҳсулоти Giga дар **Microsoft Azure** ҷойгир карда шудаанд — платформаи абрӣ, ки аз ҷониби Microsoft идора карда мешавад ва аз ҷониби ҳукуматҳо, созмонҳои байналмилалӣ ва корхонаҳо дар саросари ҷаҳон истифода мешавад. Azure ба стандартҳои ISO 27001, SOC 2 ва дигар стандартҳои байналмилалӣ мувофиқат мекунад.

Тибқи модели масъулияти муштарак (shared responsibility) дар Azure:

* **Microsoft** барои марказҳои физикии маълумот, серверҳо ва инфрасохтори шабака масъул аст
* **Giga/ЮНИСЕФ** барои амнияти барнома, идоракунии маълумот ва назорати дастрасӣ масъул аст

***

### Маълумот чӣ гуна ҳифз карда мешавад

| Чораи ҳифз | Маънои амалии он |
| --- | --- |
| Рамзгузорӣ ҳангоми интиқол | Тамоми маълумоте, ки байни барнома ва серверҳои Giga интиқол дода мешавад, рамзгузорӣ шудааст. Ягон маълумот ба таври мустақим (plaintext) интиқол намеёбад. |
| Рамзгузорӣ ҳангоми нигоҳдорӣ | Маълумоти нигоҳдошташуда дар серверҳои Giga рамзгузорӣ шудааст. Тарафҳои беиҷозат ҳатто бо дастрасии физикӣ ба сервер онро хонда наметавонанд. |
| Назорати дастрасӣ | Танҳо кормандони ваколатдори Giga ва ЮНИСЕФ метавонанд ба системаҳои бекенд дастрасӣ дошта бошанд. Дастрасӣ дар асоси нақш муайян карда мешавад ва мунтазам аз назар гузаронида мешавад. |
| Санҷиши ҳувият (Authentication) | Тамоми дастрасии API токени тасдиқшударо талаб мекунад. Дархостҳои беэътимодшуда рад карда мешаванд. |
| Санҷиши воридот (Input validation) | Барнома аз таҳдидҳои маъмулии амнияти веб (ҳамлаҳои инъексионӣ, дасткорӣ бо маълумот) муҳофизат карда шудааст. |
| Идоракунии маълумоти махфӣ (Secrets management) | Маълумоти воридшавӣ ва калидҳои танзимот бехатар нигоҳ дошта мешаванд, на дар коди барнома. |
| Муҳофизат аз таҳдидҳо | Системаи назорати амнияти Microsoft Azure фаъолияти шубҳанокро муайян ва хабар медиҳад. |
| Ҳазфи нарм (Soft delete) | Ҳазфи маълумот баргарданда аст, ки ин аз гум шудани тасодуфии доимии маълумот пешгирӣ мекунад. |

### Ба маълумоти кишвари Шумо кӣ дастрасӣ дорад

Дастрасӣ ба маълумоти сатҳи кишвар дар лавҳаи Superset дар асоси модели вобаста ба нақш сурат мегирад:

* Корбарон дар [superset.giga.global](https://superset.giga.global) ҳисоб мекушоянд
* Дастаи Giga нақши хосси кишварро таъин мекунад, то корбарон танҳо маълумоти кишварҳоеро, ки барояшон иҷозат дода шудааст, бинанд
* Ҳеҷ корбар бе иҷозати возеҳ маълумоти кишвари дигарро дида наметавонад

Барои дастрасии API ҳамин принсип татбиқ мешавад: калидҳои API ба кишварҳои муайян маҳдуд карда шудаанд ва бояд тавассути дастаи Giga дархост карда шаванд.

***

### Воридшавии ягона (SSO) ва санҷиши бисёрамрилавӣ (MFA)

Дастаи дохилии Giga ба системаҳои бекенд тавассути Microsoft Entra ID (пештара Azure AD) дастрасӣ пайдо мекунад, ки чунин имкониятҳоро таъмин мекунад:

* **Воридшавии ягона (SSO):** кормандон дар тамоми системаҳои Giga як маҷмӯи маълумоти воридшавиро истифода мебаранд
* **Санҷиши бисёрамрилавӣ (MFA):** воридшавӣ ҳам рамзи убур ва ҳам қадами иловагии тасдиқро талаб мекунад
* **Идоракунии марказонидашудаи дастрасӣ:** вақте узви даста мераваду ё нақшашро иваз мекунад, дастрасӣ аз маркази ягона хориҷ карда мешавад

***

### Амалияи таҳиякунӣ

Giga Meter тавассути хатти коркарди идорашаванда таҳия ва нашр карда мешавад:

* Код пеш аз расидан ба истеҳсолот (production) баррасӣ ва санҷида мешавад
* Абзорҳои таҳлили статикӣ пеш аз ҳар нашр осебпазириҳои маъмули амниятиро месанҷанд
* Муҳитҳои таҳия (development), санҷишӣ (staging) ва истеҳсолӣ (production) аз ҳам ҷудо нигоҳ дошта мешаванд, то тағйирот пеш аз дидани корбарон санҷида шавад
* Хатогиҳои барнома тавассути системаи худмизбонии пайгирии хатогиҳо, ки аз ҷониби ЮНИСЕФ идора карда мешавад, назорат карда мешаванд

### Инфрасохтори санҷиши суръат

Giga Meter барои гузаронидани санҷиши суръат аз [Measurement Lab (M-Lab)](https://www.measurementlab.net/) истифода мебарад — ҳамон инфрасохторе, ки санҷиши суръати Google ва дигар абзорҳои маъмули ченкунӣ истифода мебаранд. M-Lab лоиҳаи сарчашмаи кушод (open-source) аст, ки аз ҷониби шарикони академӣ ва технологӣ дар саросари ҷаҳон дастгирӣ мешавад.

M-Lab шабакаи серверҳои дар саросари ҷаҳон паҳншударо идора мекунад. Giga Meter барои ҳар санҷиш наздиктарин серверро интихоб мекунад; сервери собит истифода намешавад.

Барои сабти шабака дар рӯйхати сафед (whitelisting), як қоидаи ягонаи DNS wildcard (`*.measurementlab.net`) тамоми серверҳои M-Lab-ро фаро мегирад. Барои рӯйхати пурра ба [Танзимоти шабака ва девори оташин](../../technical-reference/network-destinations.md) (бо забони англисӣ) нигаред.
