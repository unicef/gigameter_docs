# Талаботи система

### Талаботи ҳадди ақал

Барои насб кардани Giga Meter, компютер бояд ба ин талаботи ҳадди ақал ҷавобгӯ бошад:

| Талабот                    | Тавсиф                                              |
| --------------------------- | ---------------------------------------------------- |
| **Системаи амалиётӣ**        | Windows 7 ва болотар                                 |
| **Навъи компютер**           | Компютери мизи корӣ ё лэптоп                         |
| **Пайвастшавии интернет**    | Пайвастшавии фаъол дар мактаб                        |
| **Ҷои холии диск**           | Ҳадди ақал 500 МБ                                    |
| **Тарзи истифода**           | Истифодаи мунтазам, беҳтараш ҳаррӯза                 |
| **Шабака**                   | Танҳо ба интернети мактаб пайваст                    |

***

**Ба як мактаб чанд компютер лозим аст?**

Барои оғоз як компютер кофист — компютере, ки дар давоми соатҳои таълим фаъол мемонад, ҳисоботи мактабро таъмин мекунад. Шумо метавонед то 5 компютерро дар як мактаб ба қайд гиред; компютерҳои бештар ченкуниҳои зуд-зудтар ва эҳтиёт медиҳанд, агар яке хомӯш шавад.
{% endcolumn %}

{% column %}
<img src="https://gigabrand.vercel.app/illustrations/general/fill/connection.svg" alt="" height="100">

**Пайвастшавии симдор афзалтар аст**

Дар ҳолати имконпазир, ҳадди ақал дар як компютери тавассути кабели Ethernet пайвастшуда насб кунед. Пайвастшавии симдор санҷиши суръати устувортар ва дақиқтарро таъмин мекунад.
{% endcolumn %}
{% endcolumns %}

**Компютерро фаъол нигоҳ доред**

Барнома дар замина, вақте ки компютер фаъол аст, кор мекунад. Онро дар давоми соатҳои таълим фаъол нигоҳ доред; санҷишҳо ҳангоми хомӯш будан ё дар ҳолати хоб будани компютер иҷро намешаванд.
{% endcolumn %}

{% column %}
<img src="https://gigabrand.vercel.app/illustrations/general/fill/people.svg" alt="" height="100">

**Ҳисобҳои гуногуни корбар**

Агар компютер якчанд ҳисоби корбар дошта бошад, Giga Meter-ро дар ҳар яки онҳо ба қайд гиред, то ҳамаи ченкуниҳо ба мактаб пайваст бошанд.
{% endcolumn %}
{% endcolumns %}

{% hint style="success" %}
Агар баъдтар ҳисобҳои нави корбар илова шаванд, Giga Meter-ро дар ҳамон ҳисобҳо низ насб ва ба қайд гиред.
{% endhint %}

{% hint style="warning" %}
**Giga Meter-ро навсозишуда нигоҳ доред.** Огоҳиномаҳои навсозӣ ҳамчун паёмҳои пайдошаванда намоён мешаванд. Ҳангоми дархост, барномаро аз нав оғоз кунед ва дастурҳои дар экран нишондодашударо иҷро кунед. Истифодаи версияи кӯҳна метавонад ба дақиқӣ ва пуррагии ченкуниҳо таъсир расонад.
{% endhint %}
