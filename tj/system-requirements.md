# Талаботи система

### Талаботи ҳадди ақал

Барои насб кардани Giga Meter, компютер бояд ин талаботи ҳадди ақалро қонеъ гардонад:

| Талабот                     | Тавсиф                                      |
| ---------------------------- | -------------------------------------------- |
| **Системаи амалиётӣ**         | Windows 10 ва боло                           |
| **Навъи компютер**            | Компютери мизи корӣ ё лэптоп                 |
| **Пайвастшавии интернет**     | Пайвастшавии фаъол дар мактаб                |
| **Ҷои холии диск**            | ҳадди ақал 500 МБ                            |
| **Тарзи истифода**            | Мунтазам истифода шавад, беҳтараш ҳар рӯз    |
| **Шабака**                    | Танҳо ба интернети мактаб пайваст бошад      |

***

**Дар як мактаб чанд компютер лозим аст?**

Барои оғоз як компютер кофӣ аст - агар як компютер дар давоми соатҳои таълим фаъол бошад, мактаби Шумо гузоришдиҳиро идома медиҳад. Шумо метавонед то 5 компютерро дар як мактаб қайд кунед; компютерҳои бештар ченкуниҳои зудтарро таъмин мекунанд ва агар яке хомуш шавад, эҳтиёти дигар мемонад.
{% endcolumn %}

{% column %}
<img src="https://gigabrand.vercel.app/illustrations/general/fill/connection.svg" alt="" height="100">

**Пайвастшавии симдор тавсия дода мешавад**

Дар ҳолати имконпазир, барномаро ҳадди ақал дар як компютери ба Ethernet пайваста насб кунед. Пайвастшавии симдор санҷиши суръати устувор ва дақиқтар медиҳад.
{% endcolumn %}
{% endcolumns %}

**Компютерро фаъол нигоҳ доред**

Барнома ҳангоме ки компютер фаъол аст, дар паси замина кор мекунад. Онро дар давоми соатҳои таълим фаъол нигоҳ доред; вақте ки компютер хомуш аст ё дар ҳолати хоб қарор дорад, санҷишҳо иҷро намешаванд.
{% endcolumn %}

{% column %}
<img src="https://gigabrand.vercel.app/illustrations/general/fill/people.svg" alt="" height="100">

**Якчанд ҳисоби корбарӣ**

Агар компютер якчанд ҳисоби корбарӣ дошта бошад, Giga Meter-ро дар ҳар як ҳисоб қайд кунед, то ки ҳамаи ченкуниҳо ба мактаб алоқаманд бошанд.
{% endcolumn %}
{% endcolumns %}

{% hint style="success" %}
Агар баъдтар ҳисобҳои нави корбарӣ илова шаванд, Giga Meter-ро дар онҳо низ насб ва қайд кунед.
{% endhint %}

{% hint style="warning" %}
**Giga Meter-ро ҳамеша навсозӣ кунед.** Огоҳиномаҳои навсозӣ ҳамчун паёмҳои зуҳурӣ (pop-up) намоён мешаванд. Ҳангоми пешниҳод шудан, барномаро дубора оғоз кунед ва дастурҳои рӯи экранро иҷро намоед. Истифодаи версияи кӯҳна метавонад ба дақиқӣ ва пуррагии ченкуниҳо таъсир расонад.
{% endhint %}
