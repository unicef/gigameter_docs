# Муқаддима

{% hint style="info" %}
**Giga Meter 2.0.3 — 2026-05-20**

Giga Meter акнун метавонад суръати интернетро дақиқтар чен карда, маҳалли ҷойгиршавии шуморо ба таври худкор муайян кунад. Ҳоло барнома бо забони тоҷикӣ низ дастрас аст, ҳамчунин шомили такмилҳо дар самти пайгирии истифодаи барнома ва таъмини амнияти навсозиҳо мебошад.

[Чӣ тавр аз панели идоракунӣ (дашборд) истифода бояд кард](orisoz-dar-kishvar/istifodai-dashbord.md) →

[Феҳристи пурраи тағйироту навсозиҳо](https://github.com/unicef/project-connect-daily-check-app/releases/tag/v2.0.3) [→](/broken/pages/nRdUPVFAWrn36HN2LsJI)
{% endhint %}

{% hint style="warning" %}
**Версияҳои пеш аз 1.0.10 дигар дастгирӣ намешаванд**. Мактабҳое, ки аз Giga Meter версияи 1.0.9 ё кӯҳнатар истифода мебаранд, бояд версияи охиринро аз сомонаи [meter.giga.global](https://meter.giga.global) насб кунанд. Ин талабот ба ҳамаи компютерҳое дахл дорад, ки дар онҳо Giga Meter моҳи октябри соли 2024 ё пеш аз он насб шуда, аз он вақт инҷониб навсозӣ нашудааст.
{% endhint %}

Giga Meter барномаи компютерӣ бо матни кушода аст, ки сифати пайвастшавии мактабҳоро ба интернет чен мекунад. Он дар давоми рӯзи корӣ ба таври худкор санҷишҳо гузаронида, натиҷаҳоро ба [Giga Maps](https://maps.giga.global/) - харитаи ҷаҳонии пайвастшавии мактабҳо ба интернет - ирсол мекунад. Giga Meter аз ҷониби [Giga](https://giga.global/), ташаббуси муштараки UNICEF–ITU таҳия шудааст, ки ҳадафи он ба интернет пайваст кардани тамоми мактабҳо мебошад.
